# Portfolio

A modern, responsive portfolio website crafted with semantic HTML, advanced CSS3 architecture, and interactive JavaScript.

## Features

- **Responsive Design** - Works seamlessly across all devices
- **Dark/Light Theme Toggle** - Theme preference saved to localStorage
- **Modern CSS Architecture** - CSS variables, gradients, and animations
- **Semantic HTML** - Accessible markup with proper ARIA labels
- **Performance-First** - Optimized for speed and user experience

## Files

- `index.html` - Main portfolio page
- `styles.css` - Complete styling with theme support
- `script.js` - Theme toggle and interactivity
- `.gitignore` - Git ignore rules

## Getting Started

Simply open `index.html` in your browser to view the portfolio.

## Customization

- Edit the hero section in `index.html` with your information
- Update CSS variables in `styles.css` for custom colors
- Modify project cards and experience timeline as needed
